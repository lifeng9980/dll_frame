# IR SDK 客户接入说明

## 包内目录

| 目录 | 内容 |
|---|---|
| `include/` | 稳定的 C 接口头文件 |
| `windows-x64/bin/` | `IR_station.dll`、`IR_analysis.dll` 和配方命令行 |
| `windows-x64/lib/` | MSVC 导入库，供客户编译 C/C++ 程序 |
| `linux-x86_64/lib/` | `libIR_station.so` 和 `libIR_analysis.so` |
| `linux-x86_64/bin/` | Linux 配方命令行 |
| `recipes/`、`data/` | JSON 配方、设备模板和两帧离线样例 |
| `examples/` | C、C++、C# 和 Python 调用样例 |
| `docs/` | 本说明、开发规范、设备支持矩阵和验证记录 |

应用随目标平台部署两个 SDK 库。Station 会加载同目录的 Analysis。包中没有 Qt、Asio 或 JSON 运行库。Windows 客户机需要安装相应的 MSVC x64 Runtime；Linux 需要系统 C/C++ 运行库。

## 第一次离线运行

从 SDK 根目录运行随包配方：

```powershell
& '.\windows-x64\bin\ir_run_recipe.exe' '.\recipes\noise_offline.json'
```

```bash
./linux-x86_64/bin/ir_run_recipe ./recipes/noise_offline.json
```

输入是 `data/raw16/` 中两个单像元帧 `[20, 22]`。运行应报告 `completed=2`、`mean_dn=21`、`temporal_noise_dn=1.4142135623730951`。结果写入 `output/offline-noise-example/`，包含 `frames.raw`、`frames.csv` 和 `result.json`。再次运行前将配方中的输出目录改为一个新目录，SDK 不会覆盖已有结果。

配方里的 RAW 和输出路径以 JSON 文件所在目录为基准。Windows 和 Linux 的路径参数统一按 UTF-8 处理；CLI 在 Windows 使用宽字符命令行，因此配方路径可以含中文或空格。

## 修改设备配方

复制 `recipes/noise_directshow.template.json` 或 `recipes/noise_v4l2.template.json`，按设备现场修改：

- `capture.backend` 选择 `directshow`、`v4l2` 或 `raw_replay`。
- `capture.source` 填相机名称、视频节点或 RAW 目录。
- `capture.valid_bits` 填探测器的有效位数，未知时填 `0`。
- `noise` 给出配方版本、帧数和单帧超时。
- `output_directory` 指向一个尚不存在的结果目录。
- `blackbody` 可选。填入型号、TCP/串口连接 JSON、目标温度和等稳条件后，流程会设温、等稳、取帧、计算并保存。

模板中的设备名、地址、端口、序列号和稳定条件是示意值，连接真实硬件前要换成现场确认的数据。配置中不包含产品合格限值，调用程序或量产配方负责判断合格、不合格或测量异常。

## 从 C 或 C++ 调用

`examples/CMakeLists.txt` 是客户侧独立工程。它从 `IR_SDK_ROOT` 加载公共头文件、导入库和运行库，构建纯 C、C++ 及 JSON 配方命令行样例：

```powershell
cmake -S .\examples -B .\build-client -DIR_SDK_ROOT="$PWD"
cmake --build .\build-client --config Release
```

```bash
cmake -S examples -B build-client -DIR_SDK_ROOT="$PWD"
cmake --build build-client --config Release
```

C/C++ 应用通过 `include/IR_station.h`、`IR_device.h` 和 `IR_analysis.h` 调用 C ABI。Windows 链接 `windows-x64/lib/*.lib`，部署 `windows-x64/bin/*.dll`。Linux 链接 `linux-x86_64/lib/*.so`；配套 CMake 会将库复制到示例程序目录。

## 从 C# 调用

`examples/csharp/IRSdkSample.csproj` 面向 .NET 10。它使用普通 P/Invoke，不需要 C++/CLI。结构体布局、`ulong` 句柄和 UTF-8 字符串的写法可直接作为业务程序的起点。

Windows PowerShell：

```powershell
$env:IR_SDK_LIB_DIR = (Resolve-Path '.\windows-x64\bin').Path
dotnet run --project .\examples\csharp\IRSdkSample.csproj -- .\data\raw16 .\output\csharp-run
```

Ubuntu：

```bash
export IR_SDK_LIB_DIR="$PWD/linux-x86_64/lib"
dotnet run --project examples/csharp/IRSdkSample.csproj -- data/raw16 output/csharp-run
```

省略输出目录时只计算并返回结果。传入目录时它必须是新的目录。

## 从 Python 调用

`examples/python/ir_noise.py` 用 Python 标准库 `ctypes` 直接调用 C ABI，不需要额外 pip 包：

```powershell
& 'D:\CS\py\.venv_3_12\Scripts\python.exe' .\examples\python\ir_noise.py .\data\raw16
```

```bash
python3 examples/python/ir_noise.py data/raw16 --output output/python-run
```

Python 会从包内平台目录加载 Station，也可通过 `IR_SDK_LIB_DIR` 或 `--library-dir` 指定库目录。

## 多线程和错误处理

一进程同时打开一个采集源。打开、启动、取帧、停止、关闭和固定流程由同一个工作线程执行；其他线程只调用 `IR_RequestStop` 请求取消。流程预约的设备不能被另一线程并行设温、读取或关闭。未加入当前流程的可选仪器不要求连接。

所有同步函数返回 `IRStatus`。检查返回码和错误缓冲区，不把超时、取消、断帧或设备断连当作有效指标。失败时 `IRNoiseResult.completed` 表示已完整交付的帧数；`failed_step` 和 `cleanup_status` 分别标出失败步骤及采集收尾结果。
