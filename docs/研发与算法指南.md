# IR SDK 研发与算法接入指南

> 本文件仅保留在源码仓库（不打入客户交付包）。仓库级目录分类、单向依赖红线与构建验收命令见 [AGENTS.md](../AGENTS.md)。

## 1. 模块扩展与 C ABI 约定

| 扩展目标 | 源码位置 | 关键约束 |
|---|---|---|
| 新增仪器协议 | `station/instruments/`（头文件并入 `drivers.h`） | 只处理该型号指令编码、身份校验与有限重试；共用 `asio_link.cpp`；驱动之间严禁互调 |
| 新增实时采集后端 | `station/acquisition/*_source.cpp` | 实现 `FrameSource`；当前 DirectShow / V4L2 交付紧密排列 `[帧][行][列]` U16；离线 RAW 回放另支持 RAW16 与 RAW32_LE；不伪造帧戳/不做 RGB 转换 |
| 新增数学/图像算子 | `analysis/` + `include/IR_analysis.h` | 纯 C++20（零 Qt/OpenCV/硬件 IO）；数组输入使用带元素类型、字节长度和形状的 `IRArrayView`，缓冲区由调用方持有 |
| 接入 `schemav` 配方 | `station/procedures/metrics_{basic,standard}.cpp` | 在 `recipe_metrics.cpp` 登记；若需免重编核心库分发，改用 `include/IR_plugin_abi.h` 动态插件 |

## 2. 算法规格卡与数值口径

新增指标编码前需明确以下契约：
- **标准差口径**：`temporal_noise` 固定使用逐像元样本标准差（`IR_FrameStatistics(..., sample_std = 1)`，分母 `N - 1`）；GB/GJB 噪声图 `vn` 使用总体标准差（`sample_std = 0`，分母 `N`），二者通过独立指标名区分。
- **存储类型与物理模型分开**：U32 输入能力只保证通用图像算子保留高位 DN；当前 GB/GJB 配方仍使用现有物理量模型，`valid_bits > 16` 或 U32 位宽未知时预检拒绝这些指标。不得把 `valid_bits` 自动当作 `digital_full`、ADC 满量程或探测器饱和点。
- **掩码约定**：紧密排列 `[行][列]` `uint8_t` 数组，在 C 头文件显式声明 `0/1` 含义（如 `1 = 有效像元` 或 `1 = 盲元`）及 `mask == NULL` 的全图默认行为。
- **测试验证**：在 `sdk_tests/` 使用极小数组手算基准（如 `2×2×2`）与离线 RAW 复算，并在预先声明的浮点容差（如 `<= 1e-8 DN` 或 `<= 1e-12`）内通过。

## 3. 流程执行与诊断落盘说明

配方由 `recipe_parse.cpp` 解析成带类型步骤，`recipe_metrics.cpp` 与 `metrics_{basic,standard}.cpp` 登记内置算子，`recipe_instruments.cpp` 与 `recipe_runner.cpp` 协调仪器预约、采集、安全待机收尾与落盘，`recipe_json.cpp` 作为唯一组合根注入 `PluginMetricProvider` 并暴露 `IR_CheckRecipeJson` / `IR_RunRecipeJson`。本次运行可独占并写入输出目录时，执行失败或取消也会生成诊断 `result.json`。`IR_BUSY` 仅返回状态。

插件目录扫描时跳过已加载且没有 `ir_plugin_query` 的辅助库。显式指定的插件文件必须导出该符号。插件执行时用 `has_slot` 查询可选绑定，已绑定的输入才调用 `get_slot`。

## 4. 本地调试与交付边界

- **本地调试**：用 `cmake --preset windows` 配置并复用 `实验/build-debug`，再用 `cmake --build --preset windows` 增量构建。源码树内运行 C# 或 Python 示例时，将 `IR_SDK_LIB_DIR` 设置为调试产物的绝对 `bin` 路径。
- **Windows 交付**：`verify_windows.ps1 -Configuration Release` 使用 `windows-release`，完成构建、CTest、安装、打包及包内冒烟。打包检查所有随包 `.dll` 和 `.exe` 的 Debug CRT 导入。
- **交付卫生**：客户包仅安装 `SDK.md`、`docs/客户接入说明.md`、`include/`、`examples/`、`simulators/` 与平台二进制；严禁在入包文件出现个人盘符、内部分支名或关联项目名。
