# 第三方组件

| 组件 | 版本 | 用途 | 运行时是否需要独立部署 | 许可证 |
|---|---:|---|---|---|
| standalone Asio | 1.36.0 | `IR_station` 内部 TCP 与串口 I/O | 否，编入 IR 二进制 | Boost Software License 1.0，随源码包提供上游头文件归档及许可 |
| nlohmann/json | 3.12.0 | 黑体连接 JSON、配方命令行和结果 JSON | 否，头文件编入 Station/命令行 | MIT，随包提供 `third_party/nlohmann_json/LICENSE.MIT` |

客户应用只面对 IR 的 C ABI，不包含 Asio 或 nlohmann/json 头文件，也不需要把这些库加入自己的运行目录。Windows 仍需 MSVC x64 运行库；Linux 使用发行版 C/C++ 运行库。
