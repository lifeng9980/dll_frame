# 第三方组件

| 组件 | 版本 | 用途 | 客户运行时是否需要 | 源码与许可证 |
|---|---:|---|---|---|
| standalone Asio | 1.36.0 | `IR_station` 内部 TCP 与串口 I/O | 否，编入 IR 二进制 | 源码位于 `third_party/asio/`；Boost Software License 1.0 |
| nlohmann/json | 3.12.0 | 设备配置、流程命令行和结果 JSON | 否，头文件编入 Station/命令行 | 源码和 MIT 许可证随 SDK 样例包提供 |

完整源码检出默认使用仓库内的 Asio 头文件，构建时无需另行下载。CMake 安装阶段只安装客户侧 C++ 配方示例需要的 nlohmann/json，不把 Asio 源码复制进客户包。客户应用只面对 IR 的 C ABI，不包含 Asio 或 nlohmann/json 头文件，也不需要把这些库加入运行目录。Windows 仍需 MSVC x64 运行库；Linux 使用发行版 C/C++ 运行库。
