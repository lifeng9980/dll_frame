## 运行环境基线

- **Windows x64**：需要 MSVC x64 运行库（Visual C++ Redistributable）；`IR_station.dll` 与 `IR_analysis.dll` 不依赖 Qt、OpenCV 或独立 Asio/JSON 动态库。
- **Linux x86_64**（双平台包）：预编译库在 Ubuntu 24.04 x86_64 上构建，运行时需要系统 **GLIBC 2.38+** 与对应 `libstdc++`；不依赖 Qt、OpenCV 或独立 Asio/JSON 动态库。

## 标准差口径说明

- 既有 `IR_RunNoise` 与 JSON 配方 `temporal_noise` 输出的 `temporal_noise_dn` 采用逐像元**样本标准差**（`IR_FrameStatisticsU16` 参数 `sample_std = 1`，分母 `N - 1`）的全图均值，方法名记为 `mean_pixel_sample_std`，为保持接口与历史结果兼容而固定不变。
- GB / GJB 指标（`IR_GbEvaluateMaps`、`IR_GjbEvaluateMaps`）输入的逐像元噪声图 `vn` 采用**总体标准差**（`IR_FrameStatisticsU16` 参数 `sample_std = 0`，分母 `N`），通过独立 C API 交付，不影响既有 `temporal_noise_dn` 的定义。
- Noise3D 中的 `total_blind_mask` 约定为 `1 = 盲元、0 = 有效像元`，`valid_mask` 约定为 `1 = 有效像元、0 = 盲元`；GB / GJB 的 `*bad_mask` 均为 `1 = 盲元、0 = 非盲元`，`valid_mask` 均为 `1 = 有效像元、0 = 盲元`。
