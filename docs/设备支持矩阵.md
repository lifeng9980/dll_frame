# IR SDK 设备支持矩阵

“编译”表示源码包含该后端；“模拟/离线”表示相应用例通过；“真机”只在有明确设备测试证据时标为通过。

| 能力 | Windows x64 | Ubuntu 24.04 x86_64 / WSL2 | 说明 |
|---|---|---|---|
| RAW16 回放 | 已验证 | 已验证 | 支持按 `frames.csv` 索引读取，并保存 RAW/元数据/指标后重放 |
| FX3 UVC DirectShow | 已编译；本轮未做 Windows 真机验收 | 不适用 | 需要现有 DirectShow Sample Grabber COM 组件及设备运行环境 |
| FX3 UVC V4L2 | 不适用 | 已编译；USB/IP 真机连续帧未通过 | 既有试验读到首帧，随后检测到序号跳变；不作为连续采集验收通过 |
| PCN7-LT TCP 黑体 | TCP 模拟通过 | TCP 模拟通过 | 真实黑体/探头身份的工位验收未完成 |
| DCN1000 串口黑体 | 当前只编译，未做本轮 Windows 串口模拟 | 虚拟串口模拟通过 | 真实串口设备验收未完成 |
| PCIe-1433 NI-IMAQ | 暂不支持 | 暂不支持 | 枚举编号保留，调用返回 `IR_UNSUPPORTED` |
| 基础时域噪声 | 已验证 | 已验证 | 全图均值和平均像元样本标准差，单位 DN |
| GJB / EMVA 1288 指标 | 未实现 | 未实现 | 等具体标准版本、条款、帧条件和参考数据确定后逐项接入 |
| 电源、万用表、烘箱、探测器控制 | 尚未接入首版 SDK | 尚未接入首版 SDK | 现有上位机代码只作型号适配参考，接入后分别验收 |
